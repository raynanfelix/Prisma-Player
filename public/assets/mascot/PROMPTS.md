# Prompts para Mascote Arara — Prisma Player

**Pasta de destino:** `public/assets/mascot/`
**Formato:** 1536×1536 (1:1), fundo sólido, 3 cores semânticas (2 IP + 1 fundo)
**Estilo:** Ultra-simplificado, fofo, legível em 32×32, cantos arredondados pesados

---

## Paleta base
- **Verde marca** (fundo ou cor principal): `#16A34A` / `#22C55E` / `#15803D`
- **Cores Arara** (escolher 2): Azul `#2563EB` + Amarelo `#FACC15` | ou Azul `#1E40AF` + Laranja `#FB923C`
- **Fundo suavizado:** Verde marca com saturação -20% (ex: `#1E8A3E` → `#3D9E5E`)

Keep the IP, facial marks, and background clearly separated.
Composition: keep the character upright and emerging from the lower-left, filling about 85–95% of the square so it remains visually dominant. Cropping at the bottom or left side is welcome when it strengthens the corner emergence. Preserve both paired identifying features (both eyes visible). Never center or bottom-center the character.
Style: make simplification, cuteness, and lovable baby-like appeal the strongest qualities. Use large soft forms, compact proportions, thick rounded contours, and an ultra-clean graphic treatment. Prefer one clear shape over several explanatory details. Add an extremely, extremely subtle, almost imperceptible sense of depth through a barely-there neo-skeuomorphic treatment.
Finish: show only the character on the full-canvas background, with clean surfaces and normal square outer corners.
Constraints: Use no text or watermark. Add no borders, frames, cards, or presentation masks. Include one character only, with no extra subjects or scenery. Use no fragile lines, sharp tips, unnecessary outlines, tiny details, or decorative marks. Add no photorealistic material, dramatic bevel, glossy hotspot, deep occlusion, extrusion, strong three-dimensional rendering, or external cast shadow. Keep the background solid and uniform, with no texture, vignette, or lighting variation.

## Como gerar

### Opção 1: Gemini / Nano Banana (Google AI Studio)
1. Acesse https://aistudio.google.com
2. Selecione modelo **Gemini 2.5 Flash Image** ou **Nano Banana Pro**
3. Cole cada prompt acima (um por vez)
4. Salve como `A1.png`, `A2.png`, `B1.png`, `B2.png`, `C1.png`, `C2.png` em `public/assets/mascot/`

### Opção 2: GPT Image / ChatGPT Images (OpenAI)
1. Use ChatGPT com GPT-4o ou API `gpt-image-1`
2. Cole os prompts
3. Mesma nomenclatura de arquivos

### Opção 3: Flux (Replicate / fal.ai / BFL)
```bash
# Exemplo Replicate
replicate run black-forest-labs/flux-pro-1.1 -i prompt="<PROMPT_AQUI>" -i aspect_ratio="1:1" -i output_format="png"
```

### Opção 4: Ideogram 3.0 (se precisar de texto no futuro)
- Melhor para tipografia, mas também gera ilustrações limpas
